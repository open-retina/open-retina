# Core Functionality

OpenRetina connects retinal datasets, model architectures, training workflows, evaluation tools, and in-silico analyses through shared interfaces.

- [Data I/O](../data_io.md) describes stimulus and response containers, dataset loaders, and the HDF5 interchange format.
- [Training](../training/index.md) covers model construction, configuration-driven training, and evaluation.
- [In-silico experiments](../insilico/index.md) covers stimulus optimisation, response tuning, weight visualisation, and local spike-triggered averages.
- [API reference](../../api_reference/index.md) documents the public Python interfaces.
