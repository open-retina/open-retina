# Datasets

OpenRetina currently provides loaders for five published retinal datasets. The [Data I/O guide](../data_io.md) explains the common interfaces and how to integrate additional datasets.

- [Höfling et al., 2024](../../api_reference/data_io/hoefling_2024.md) — mouse retinal responses to natural stimuli.
- [Karamanlis et al., 2024](../../api_reference/data_io/karamanlis_2024.md) — mouse and marmoset retinal responses to natural scenes.
- [Maheswaranathan et al., 2023](../../api_reference/data_io/maheswaranathan_2023.md) — tiger salamander retinal responses to natural scenes.
- [Goldin et al., 2022](../../api_reference/data_io/goldin_2022.md) — mouse retinal responses under varying visual contexts.
- [Sridhar et al., 2025](../../api_reference/data_io/sridhar_2025.md) — marmoset retinal responses to natural movies and white noise.

Mirrored datasets are available from the [OpenRetina collection on Hugging Face](https://huggingface.co/datasets/open-retina/open-retina).
